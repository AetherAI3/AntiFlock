# AntiFl0ck brand assets

Source artwork is a raster illustration; these exports carry genuine alpha
transparency (the original checkerboard was baked into the pixels and has been
removed). A true vector (SVG) redraw of the eagle is an open design task.

| File | Use |
| --- | --- |
| `antifl0ck-lockup.png` | Full eagle + wordmark, 1600 px — print/large surfaces |
| `antifl0ck-lockup-hero.png` | Same lockup, 760 px — README hero |
| `antifl0ck-mark.png` | Eagle + flock-network mark, 1024 px |
| `antifl0ck-mark-512.png` | Mark, 512 px — avatars, embeds |
| `antifl0ck-wordmark.png` | Wordmark band, 1200 px |
| `antifl0ck-banner.svg` | 1600×640 landscape banner (mark embedded) |
| `evidence-scale.svg` | Evidence-taxonomy strip used in the README |
| `../social-preview.png` | 1280×640 GitHub social preview (upload in repo Settings) |
| `../demo/coffee-shop.svg` | Animated coffee-shop lifecycle card |

Dark-background assets: the mark and lockup sit on transparency and read best
on dark or mid surfaces; the baked outline keeps them legible on white.

Usage: the code in this repository is Apache-2.0, but the AntiFl0ck name and
these marks identify the project — see [TRADEMARKS.md](../../TRADEMARKS.md).
