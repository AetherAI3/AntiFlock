# Trademark and brand policy

The source code in this repository is licensed under the
[Apache License 2.0](LICENSE). That license covers the **code**. It does not
grant permission to use the project's names or visual identity, and this
document explains what is and is not okay.

## Project marks

- the name **AntiFl0ck** (and the stylized wordmark);
- the **eagle / flock-network mark** and the lockups in
  [`assets/brand/`](assets/brand/);
- the project's official visual identity as used in this repository.

## You may, without asking

- use the name to truthfully refer to the project ("built on AntiFl0ck",
  "compatible with AntiFl0ck", "a fork of AntiFl0ck");
- keep the marks intact in unmodified redistributions of this repository;
- show the marks in articles, talks, reviews, and research about the project.

## Please don't

- use the name or marks in a way that implies your product, fork, or service is
  official, endorsed, or maintained by this project when it is not;
- use the marks as the primary branding of a modified distribution — rename
  your distribution and state that it is derived from AntiFl0ck;
- register domains, accounts, or packages designed to be confused with the
  project.

## Working-title note

*AntiFlock* (no zero) was an internal working title that collides with an
unrelated existing project; **AntiFl0ck** is the public name. This project
claims nothing over that other project's name, and internal identifiers are
still being migrated (see [docs/REBRAND.md](docs/REBRAND.md)).

Questions about a specific use are welcome — open a discussion or issue.
